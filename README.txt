PIXELPORT — WEBSITE STARTER
Working brand name: PixelPort (can be renamed later).

Files: index.html (frontend), manifest.json (PWA), sw.js (basic shell cache), icon.svg.

Includes responsive homepage, Leaflet/OpenStreetMap café map, area search, PC price and setup filters, browser location and distance sorting, demo café cards, owner listing form with photo previews, player/business login UI, tournament/team sections, PWA install foundation.

IMPORTANT: This is a frontend prototype only. Sample cafés and events are illustrative and not verified. Login does not create accounts. Café form stores a temporary card only in the current browser; it does not upload images, send an application, publish a listing, or sync between devices. No database, secure admin dashboard, business verification, email verification, or review system is connected yet. Do not enter real passwords or upload private proof documents.

To publish: upload these files to the root of a public GitHub repository, then Settings > Pages > Deploy from a branch > main > /(root) > Save. Wait for the GitHub Pages URL. Real accounts/listings need a backend (e.g. Supabase), secure role permissions, database Row Level Security, private image storage, validation, admin approval and privacy policy. Free plans have usage limits. Use the github.io address to avoid a paid domain. Map tiles have usage policies; check OpenStreetMap tile usage before production/high traffic.
